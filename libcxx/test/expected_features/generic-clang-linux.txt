# Golden file for all Clang-on-Linux CI builders.
#
# This file contains Lit features that must be available in ALL Clang-on-Linux
# CI configurations. If a feature listed here is not detected, it means the
# CI configuration has changed unexpectedly and tests may be silently disabled.
#
# Only auto-detected features are listed here. Parameter-driven features like
# std, optimization, stdlib, hardening_mode, etc. are intentionally excluded
# because those would fail loudly if misconfigured.
#
# Features that are NOT shared by all Clang-on-Linux builders (e.g.
# libcpp-has-thread-api-pthread is missing from generic-no-threads, and
# locale.* features are missing from generic-no-localization) are excluded.
#
# Builders using this file:
#   generic-cxx03, generic-cxx11, generic-cxx14, generic-cxx17, generic-cxx20,
#   generic-cxx23, generic-cxx26, generic-modules, generic-modules-cxx17-lsv,
#   generic-merged, generic-static, generic-optimized-speed,
#   generic-no-exceptions, generic-no-experimental, generic-no-filesystem,
#   generic-no-localization, generic-no-random_device, generic-no-threads,
#   generic-no-tzdb, generic-no-unicode, generic-no-wide-characters,
#   generic-no-rtti, generic-hardening-mode-debug,
#   generic-hardening-mode-extensive, generic-hardening-mode-fast,
